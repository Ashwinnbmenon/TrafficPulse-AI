# 🚦 TrafficPulse AI – Traffic Congestion Prediction

## 📌 Project Overview
TrafficPulse AI is a machine learning-based web application that predicts traffic congestion levels using traffic-related data.

The system analyzes traffic information and predicts congestion to help users understand traffic conditions and support better traffic management.

## 🎯 Objectives
- Predict traffic congestion using machine learning.
- Analyze traffic patterns and trends.
- Visualize traffic data through interactive graphs.
- Provide an easy-to-use web application.

## 🛠️ Technologies Used
- Python
- Machine Learning
- Scikit-learn
- XGBoost
- Pandas
- NumPy
- Streamlit
- Plotly
- Matplotlib
- Seaborn

## 🤖 Machine Learning
The project uses trained machine learning models to classify traffic congestion levels.

## 📊 Features
- Traffic congestion prediction
- Interactive data visualizations
- Traffic data analysis
- User-friendly dashboard
- Machine learning-based predictions

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/Ashwinnbmenon/TrafficPulse-AI.git
```

2. Open the project folder:

```bash
cd TrafficPulse-AI
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
streamlit run app.py
```
